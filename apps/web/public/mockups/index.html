BellMarkets — Visual Direction Progression

Seven high-fidelity HTML mockups exploring distinct design philosophies for a non-custodial Solana binary-options dApp. Each candidate is a coherent design system applied across the landing page and trading terminal. v1–v5 are the initial exploration; v6 and v7 are feedback-driven redesigns incorporating layout corrections, polish elements, and "wow" interactions per design-feedback-cory.md. Pick one as the foundation; combine elements if useful.

What you're looking at

Each candidate has two files: vN-landing.html (markets list) and vN-trade.html (trading terminal — the load-bearing page). All five share the same content (MAG7 stocks, prices, wallet addresses, program ID) so direct comparison is apples-to-apples.

Every candidate has a dark mode default with a working light mode toggle (◐ button in the header; preference persists via localStorage).

  • v1 — Hyperliquid: max-density, mono-heavy, yellow-green. Power-user feel.
  • v2 — Polymarket: approachable, amber accent, big probability percentages.
  • v3 — Drift Protocol: Solana DeFi standard. Violet gradient + sticky bottom position monitor.
  • v4 — Bloomberg / dYdX: institutional terminal. 4-pane layout, IBM Plex Mono, cyan accent.
  • v5 — Linear: modern restrained. Sparkline-driven. Sharp orange. Most breathable.
  • v6 — Pulse (NEW): Linear-orange aesthetic with modern degen polish. Table-view markets with strike price+probability cards, animated movers carousel, Cmd-K palette, gradient borders, pulse animations, hotkey hints. Settlement preview shows 3 scenarios (exit-now / hold-yes-win / hold-yes-lose).
  • v7 — Terminal (NEW): Bloomberg-cyan terminal density with polished type. Persistent left rail navigation + color-coded probability matrix (7×7 heat-graded grid) + top status bar. On-chain info card with 16 fields. IBM Plex Mono numerics. Same 3-scenario settlement preview.

If you're choosing today: start with v6 and v7. They incorporate the layout corrections (chart-dominant trade page, order book + trades on right, position + settlement below chart), better market switching (search + Cmd-K + left rail), and richer interaction polish that addressed the "too basic" feedback on v1–v5.

08 / TERMINAL REFINED

Terminal Refinedv7 DNA + 2026-05-23 feedback applied + mobile-first

Vibe

v7 Terminal's DNA, every bullet of Cory's 2026-05-23 feedback applied. Base font 14px (was 12). WCAG AA contrast everywhere — accent cyan brightened to #22d3ee for 9.2:1 on near-black, body color lifted to #e8edf7 for 14.5:1. Logo lockup separated from MARKETS nav with explicit vertical divider + 32px gap. CNBC-style ticker marquee at top (28px, continuous scroll, pauses on hover) replaces v7's static ticker row. Session info compressed to corner module (40px tall, click to expand). Probability matrix gains a view toggle — Matrix view (dense, default) ↔ Cards view (Pulse-style, mobile-friendly). Every price cell shows "$0.84 · 84% implied" with `?` tooltip explaining the convention. Trade panel includes slippage slider with computed worst-price display.

What's new vs v7: Sidebar widgets (Weekly Leaderboard top-5, Active Contests with progress bars, Bell Pro AI teaser CTA). Mobile bottom-tab bar (Markets / Leaderboard / Contests / Profile) replaces desktop nav at <768px. Matrix horizontally scrollable on mobile with a hint to switch to Cards view. All touch targets ≥44pt. Visible focus rings everywhere. No hover-only interactions. Mobile-first responsive — designed at 375px first, expansion to desktop is the additive case.

Picking a direction

Two ways to decide:

  • Pick one outright — the candidate that nails the design DNA you want. Cleo builds the React frontend against it directly.
  • Hybrid pick — choose a base candidate, then call out 1–3 elements from other candidates to incorporate. Example: "v3 base, but use v4's status bar and v5's sparklines on the market list."

Before deciding, click into each candidate's trade page (the load-bearing UX) and toggle dark/light mode in the header. The trade page reveals more design DNA than the landing.
