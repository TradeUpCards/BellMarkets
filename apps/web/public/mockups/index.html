BellMarkets — Visual Direction Progression

Five high-fidelity HTML mockups exploring distinct design philosophies for a non-custodial Solana binary-options dApp. Each candidate is a coherent design system applied across the landing page and trading terminal. Pick one as the foundation; combine elements if useful.

What you're looking at

Each candidate has two files: vN-landing.html (markets list) and vN-trade.html (trading terminal — the load-bearing page). All five share the same content (MAG7 stocks, prices, wallet addresses, program ID) so direct comparison is apples-to-apples.

Every candidate has a dark mode default with a working light mode toggle (◐ button in the header; preference persists via localStorage).

  • v1 — Hyperliquid: max-density, mono-heavy, yellow-green. Power-user feel.
  • v2 — Polymarket: approachable, amber accent, big probability percentages.
  • v3 — Drift Protocol: Solana DeFi standard. Violet gradient + sticky bottom position monitor.
  • v4 — Bloomberg / dYdX: institutional terminal. 4-pane layout, IBM Plex Mono, cyan accent.
  • v5 — Linear: modern restrained. Sparkline-driven. Sharp orange. Most breathable.

Picking a direction

Two ways to decide:

  • Pick one outright — the candidate that nails the design DNA you want. Cleo builds the React frontend against it directly.
  • Hybrid pick — choose a base candidate, then call out 1–3 elements from other candidates to incorporate. Example: "v3 base, but use v4's status bar and v5's sparklines on the market list."

Before deciding, click into each candidate's trade page (the load-bearing UX) and toggle dark/light mode in the header. The trade page reveals more design DNA than the landing.
